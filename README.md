# k8s-learning-log

## Semaine 1 : Minikube, Deployment, ConfigMap, Service, Secret

- Cluster local avec Minikube (driver Docker)
- App Flask conteneurisée, image buildée dans le Docker de Minikube
- Deployment (2 replicas) configuré via ConfigMap et Secret
- Exposition via un Service NodePort

## Fichiers
- `app.py`, `Dockerfile`
- `configmap.yaml`, `deployment.yaml`, `service.yaml`
